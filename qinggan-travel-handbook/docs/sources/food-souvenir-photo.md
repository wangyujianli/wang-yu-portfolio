# 饮食、伴手礼与拍照点资料说明

核对日期：2026-08-01

这份记录对应 `src/data/localFood.ts`、`src/data/souvenirs.ts` 与 `src/data/photoCheckpoints.ts`。页面只呈现适合长期维护的地点常识、体验差异和现场边界，不制作餐厅榜单，不提供价格、促销、商户营业时间或购买链接。

## 来源等级

- A：地方政府、国家公园、博物馆、研究院或景区官方网站，用来核对地域文化、代表性风味、生态边界和景区体验。
- B：政府部门发布的非遗名录、产业与文旅专题，用来确认某类食物或文创确实与当地相关。
- C：路线编辑判断，用来决定某地点是直接展示内容，还是只提示到相邻成熟节点补给；不用于宣称商户经营状态。

## 地方饮食与补给

- 青海省政府的西宁文旅内容提到莫家街一带的手抓羊肉、酿皮、酸奶等地方风味；河湟饮食专题补充了当地饮食的地域背景。项目据此保留风味类别，不指定某一家店。
  - <https://www.qinghai.gov.cn/dmqh/system/2025/08/14/030079305.shtml>
  - <https://www.qinghai.gov.cn/dmqh/system/2023/12/03/030031131.shtml>
- 青海省政府关于藏羊产业的公开信息用于确认羊肉类风味与高原牧业之间的关联，不据此作品牌或品质排名。
  - <https://www.qinghai.gov.cn/zwgk/system/2024/04/17/030042021.shtml>
- 张掖市政府文旅栏目及地方志内容用于核对牛肉小饭、搓鱼子、臊面等地域饮食名称。
  - <https://www.zhangye.gov.cn/chzy/zyly/mstc/xbzyms/202606/t20260604_1550222.html>
  - <https://www.zhangye.gov.cn/chzy/zyly/mstc/xbzyms/>
  - <https://www.zhangye.gov.cn/szb/dzdt/gjzy/202110/t20211012_723060.html>
- 甘肃省文旅部门公开内容用于核对敦煌黄面、杏皮水等风味；省级非遗名录用于交叉核对敦煌杏皮水、甘州搓鱼子、甘州臊面、酒泉糊锅等项目。
  - <https://www.gswbj.gov.cn/a/2021/04/07/8433.html>
  - <https://swt.gansu.gov.cn/swt/c091601/202501/174056494/files/de9e97a51e1446bdab1d1073b2334c85.pdf>

页面中的“附近补给节点”属于路线编辑判断：公路、遗址、荒原和保护地不显示虚构的就地餐饮，只提示回到西宁、敦煌、大柴旦、德令哈、格尔木等成熟节点安排补给。

## 伴手礼与文化来源

- 敦煌研究院文化创意研究中心及其公开品牌信息用于确认敦煌文化出版物、授权纹样与正规文创的来源方向。
  - <https://www.dha.ac.cn/jggk/jgsz/ywbm/whhyb1/whcyyjzx.htm>
- 青海藏文化博物院官方网站设有文创产品内容，项目因此在该地点保留博物馆出版物与纹样纸品，而不扩展为商品商城。
  - <https://www.tibetanculturemuseum.com.cn/>
- 茶卡盐湖官方网站用于确认景区自身的盐湖文化和摄影主题，页面只保留正规包装、来源清晰的文化产品方向。
  - <https://www.chakasl.com/index.html>

所有伴手礼文案共同遵守：不采集自然盐壳、矿石、植物或沙土；不推荐野生动物来源材料；食品看生产信息和保质期；液体、喷雾与工具类按实际交通规定确认携带方式。

## 拍照点与现场边界

- 茶卡盐湖官方摄影与穿搭指南用于核对倒影、色彩和服装反差的表达方向。
  - <https://www.chakasl.com/pc/introduction/zeme/detail/747.html>
- 鸣沙山月牙泉官方网站及日出日落信息页用于核对沙丘光线和景区公开时段的表达；具体开放安排仍由票务数据单独维护。
  - <https://www.mssyyq.com/>
  - <https://www.mssyyq.com/JQRC/>
- 道路拍照边界依据道路交通安全法及实施条例整理：照片点只写合法停车点、观景区或服务区视角，不把机动车道作为拍摄位置。
  - <https://www.npc.gov.cn/zgrdw/npc/zfjc/zfjcelys/2016-12/13/content_2003512.htm>
  - <https://www.gov.cn/banshi/2005-08/23/content_25579_2.htm>
- 可可西里与藏羚羊内容依据青海省政府、三江源国家公园公开资料整理，摄影建议保持远距离观察与长焦记录，不提供追逐、投喂或离开开放道路的指引。
  - <https://www.qinghai.gov.cn/dmqh/system/2013/11/26/010087720.shtml>
  - <https://sjy.qinghai.gov.cn/stbh/26145.html>
  - <https://www.qinghai.gov.cn/zwgk/system/2026/03/02/030093820.shtml>

黑独山等存在开放范围变化的地点只写“合法开放区域”和现场标识，不给出可能诱导进入非开放区域的坐标。拍照点的构图、镜头和服装建议属于编辑经验，不宣称为景区官方机位。

## 图片说明

拍照点优先复用项目现有的本地实景图优化副本。没有对应实景图时显示统一的中性占位，不下载、不热链网络图片，也不以 AI 风景冒充现场照片。图片授权与导入规则仍以 README 的“导入本地实景图片”章节为准。
