## 修改方式

1. 在 `src/data/ticketBookings.ts` 找到地点 `id` 对应记录。
2. 只有同一条正式公告明确给出时，才分别填写 `openTime`、`lastTicketTime`、`lastCheckInTime`、`lastEntryTime`、`closeTime`。
3. 内部项目放入 `internalProjects`，不要用观光车或游船末班替代景区闭园时刻。
4. 官方信息冲突时保留 `conflictDetected: true`，并在 `conflictNote` 写明冲突，不任选一条。
5. 更新后同步修改 `lastVerifiedAt`、来源等级和本文件，再运行 `npm run test:run` 与 `npm run build`。
