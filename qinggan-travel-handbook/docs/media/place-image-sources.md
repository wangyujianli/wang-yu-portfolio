## 替换方式

将新图片放入 `public/images/places/` 并保持原文件名即可直接替换。推荐使用横向构图、宽度不低于 1600 像素的 JPG 或 PNG；重要主体尽量位于画面中间区域，兼顾地点卡片与详情页的不同裁切比例。
